# Universal Trading Bot

Universal multi-asset trading bot based on **Volume Strategy FINAL Universal v15**.

TradingView is **not required** for live execution. The bot calculates indicators/signals itself, manages positions/orders, and exposes the strategy state through a live web dashboard.

## Supported assets

- Crypto: Binance / Bitget / OKX / Bybit adapters
- Stocks / ETFs: yfinance market-data adapter + broker adapter interface
- Arbitrary supported symbols and timeframes
- One v15 strategy engine shared by all assets

## v15 strategy

- Volume average lookback + volume breakout multiplier
- Four-exchange normalized crypto volume
- One-bar volatility min/max filter
- N-bar volatility based dynamic TP/SL
- N-bar extreme-volatility entry block
- ADX min/max range filter
- RSI oversold LONG / overbought SHORT ranges
- Candle direction confirmation
- LONG / SHORT enable switches
- Pyramiding limit
- Entry cooldown + re-entry cooldown
- Start date / weekend / excluded-hour filters
- Fixed TP/SL per initial position
- Duplicate entry protection per bar
- Strategy statistics and dashboard state

The supplied Pine strategy is the source of truth. LONG uses a bearish candle + RSI oversold; SHORT uses a bullish candle + RSI overbought. TP/SL are calculated when the initial position opens and remain fixed for that position.

## 1. Install

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e .
cp .env.example .env
```

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
pip install -e .
Copy-Item .env.example .env
```

## 2. Configure `.env`

`.env` is the normal runtime configuration file and must never be committed.

Start with:

```env
BOT_MODE=PAPER
SYMBOLS=BTC/USDT,ETH/USDT
TIMEFRAME=5m
DASHBOARD_HOST=0.0.0.0
DASHBOARD_PORT=8000
```

You can replace `SYMBOLS` with any supported crypto symbols, or use stock/ETF symbols when `ASSET_CLASS=stock` / `etf` is configured.

The v15 parameters in `.env.example` correspond to the supplied TradingView v15 defaults.

## 3. Start the bot

```bash
python -m universal_bot
```

The bot starts the market-data loop and the dashboard together. Default mode is PAPER; no live order is enabled by this default.

## 4. Open the dashboard

On the same machine open:

**http://localhost:8000**

The dashboard is generated by the bot itself and refreshes every second. It shows the selected symbols, position, LONG/SHORT signal, volume ratio, one-bar volatility, N-bar range, TP/SL calculation, ADX, RSI, and trading statistics.

Health check:

**http://localhost:8000/health**

API state:

**http://localhost:8000/api/state**

## Architecture

`universal_bot/strategy/v15.py` is exchange/provider independent. Adapters translate market data and orders into a common model, so the strategy does not know whether the instrument is BTC, an altcoin, a stock, or an ETF.

The project intentionally separates strategy, market data, execution, paper trading, scanning, and dashboard layers so TradingView is not part of the trading path.

## Safety

Live trading is deliberately disabled by default. Before enabling live execution, validate symbol mapping, contract/lot size, leverage, fees, reduce-only behavior, order reconciliation, and position synchronization for the selected venue.
