# 전략 중심 차트 작업 화면

홈의 **차트 작업 화면**에서 DB 분석, 전략 검증, 거래 탐색을 시작합니다.
이 화면은 저장된 DB를 분석하는 오프라인 차트입니다.
**LIVE 서버**는 기존 SSH 인증 대시보드를 열며, 차트 분석에서 실거래 설정을 자동 변경하지 않습니다.

| 작업 | 위치 |
|---|---|
| 심볼/거래소/주기 | 상단 DB와 시장 선택 |
| 전체화면, EMA20/60/200, BB20·2σ | 차트 설정 |
| RSI14/ADX14 참고지표, 전략 정규화 거래량 | 차트 설정 → 보조지표 |
| JSON 가져오기, Pine v19 수치, 수치 편집 | 전략 |
| 수익률/MDD/순자산·낙폭/월별 실현손익 | 성과 |
| 진입/청산 표와 이전·다음 거래 이동 | 거래 및 하단 탐색 버튼 |
| 1봉 이동, 자동 재생/정지 | 리플레이 |
| 수평선/추세선, 북마크 | 그리기·저장 |
| 차트 PNG, 전략 JSON, 거래 CSV | 그리기·저장 |
| 표시 구간의 누락·중복·OHLC·4거래소 거래량 검사 | 데이터 검사 또는 경고 문구 터치 |

길게 누른 뒤 손가락을 이동하면 십자선으로 봉을 연속 조회합니다.
일반 드래그는 차트 이동, 두 손가락은 확대/축소입니다.
데이터 주의 봉은 주황색 띠로 표시하며 잘못된 OHLC는 가격 축 계산과 캔들 그리기에서 제외합니다.
데이터 검사는 표시된 구간만 대상으로 하며 리플레이 이후 봉을 검사 결과에 포함하지 않습니다.
4거래소 거래량의 존재·유효성과 전략 SMA 워밍업/신호 준비 여부는 별개입니다.
검사는 원본 DB를 수정하거나 실거래 설정을 변경하지 않습니다.

## 표시와 계산

- EMA와 볼린저밴드는 현재 표시 범위 이전의 DB 이력도 사용합니다.
  차트를 이동하거나 확대해도 동일한 봉의 지표 값은 바뀌지 않습니다.
- RSI14와 ADX14는 차트 참고지표입니다. 전략 진단 패널의 RSI/ADX는
  선택한 전략의 기간을 사용하므로 두 값을 구분합니다.
- 지표는 미래 봉을 참조하지 않습니다. 미래 가격을 바꿔도 과거 지표가
  그대로인지와 워밍업 표시를 테스트합니다.
- 수치 편집은 유한한 숫자, 양수 기간, 비용, RSI/ADX 범위, 진입 노출 한도를
  검증하며, 기존 거래 설정이나 LIVE 계정에 적용하지 않습니다.
- 성과 수치는 전체 백테스트 결과이며 순자산/낙폭 그래프는 요약 곡선입니다.
  월별 손익은 청산 UTC 월을 기준으로 합산한 실현손익입니다.

## 리플레이

처음 200봉 또는 선택 봉부터 시작합니다. 한 봉씩 이동하거나 자동 재생합니다.
리플레이 종료 전에는 이후 캔들, 이후 청산된 거래, 전체 기간의 성과를 숨깁니다.
뒤로 이동할 때는 이전 차트를 먼저 지우고 새 범위를 읽습니다.
지표 계산은 인과적이며 미래 거래와 이후 시점에 만든 그리기도 표시하지 않습니다.

이는 이미 계산한 전략 결과를 과거 봉 순서로 검토하는 기능입니다.
새로운 주문을 내거나 독립적인 모의거래 계좌를 운용하는 기능은 아닙니다.

## 작업 보존

DB·거래소·심볼·주기별로 차트 위치, 확대 수준, 지표 선택,
그리기(최대 100개), 북마크(최대 100개), 리플레이 위치를 저장합니다.
화면을 떠나면 재생은 정지합니다. 화면 회전과 폴드 크기 변경으로
차트 Activity를 다시 만들지 않도록 구성했습니다.
그리기는 메모이며 주문이나 가격 알림이 아닙니다.

## 범위

우리 전략의 DB 분석과 검증, 서버 거래 관리 이동에 초점을 맞췄습니다.
TradingView의 Pine 실행기, 모든 시장의 실시간 호가/틱 데이터,
클라우드 알림과 커뮤니티 기능을 대체한다고 주장하지 않습니다.
단말별 렌더링과 터치 성능은 APK 설치 후 확인해야 합니다.
