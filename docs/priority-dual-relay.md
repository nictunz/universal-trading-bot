# 5분봉 모바일 중계 추가

관찰 결과 2026-09-16 05:10/05:15/05:20 UTC에서 기존 앱이 15분봉만 제공해 5분봉 조회가 차단됐다. 15분봉 거래량을 나누거나 시간봉 표시만 바꾸면 실제 5분봉 데이터가 되지 않는다.

이 수정은 기존 mobile-market-relay.json(BTC/ETH 15분봉)을 유지하고, mobile-market-relay-5m.json(BTC 5분봉)을 별도로 원자 업로드한다. Binance와 Bybit 모두 각 거래소의 native 5분봉240개를 요청한다. 기존 4개 요청에 BTC5분봉2개가 추가되며 최대 동시 요청은6개다. 평상시30초 주기는 유지하고 경계 동기화는5분마다 수행하므로 기존보다 경계 구간과 요청량이 늘어난다.

15분봉 업로드를 먼저 마치고 5분봉 결과를 업로드한다. 5분봉 요청 실패는 별도로 표시하며 기존15분봉 파일을 교체하지 않는다. 서버 수신기는 요청 시간봉에 맞는 파일과 해당 파일의 관측 시각·유효기간을 검사한다. 오래된5분봉 파일을 새15분봉 파일의 시각으로 새것처럼 취급하지 않는다.

Python 로컬 검증: 기존 통합 항목을 포함135개 통과. 그 중 릴레이6개 기존 테스트와6개 추가 테스트를 포함한다. Android 소스 확인 테스트는 빌드 검증을 대신하지 않는다. 별도 GitHub workflow가 Android 컴파일을 검증하며, APK 서명·출시·서버 배포는 수행하지 않는다.

필요한 적용 순서: Android 컴파일 확인 → 업데이트용 서명 APK 빌드·설치 → 휴대폰 중계 재개 → 관찰용 Git worktree 업데이트 → 3개 경계 재확인. 새 앱이 설치되기 전에는 서버에서 관찰 명령만 반복해도5분봉 결측이 해결되지 않는다. 기존 LIVE 서버의 소스·설정·서비스는 이번 브랜치 push로 변경되지 않는다.
